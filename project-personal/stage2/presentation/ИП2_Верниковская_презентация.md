# Выполнение 2-ого этапа индивидуального проекта

## Загрузка DVWA

DVWA (Damn Vulnerable Web Application) - это веб приложение на PHP/MySQL, которое "чертовски уязвимо". Его главное цель - помочь профессионалам или новечкам протестировать их навыки в сфере инормационной безопасности. На сайте https://nooblinux.com/how-to-install-dvwa/ очень хорошо и подробно описано как устанавливать и настраивать DVWA в гостевой системе Kali Linux. Поскольку мы будем настраивать DVWA на нашем локальном хосте, запустим терминал и перейдём в /var/www/html: *cd /var/www/html*. Это место, где хранятся файлы локального хоста (рис. 1)

![Переход в каталог /var/www/html](image/ИП2_1.png){#fig:001 width=70%}

## Загрузка DVWA

Далее склонируем репозиторий https://github.com/digininja/DVWA в каталог /html с помощью команды: *sudo git clone https://github.com/digininja/DVWA* (рис. 2)

![Клонирование репозитория DVWA](image/ИП2_2.png){#fig:002 width=70%}

## Настройка DVWA

После успешного клонирования репозитория выполним команду *ls*, чтобы проверить успешное клонирование DVWA (рис. 3)

![Проверка успешного клонирования](image/ИП2_3.png){#fig:003 width=70%}

## Настройка DVWA

Теперь назначим разрешения Read, Write и Execute (777) для папки DVWA. Для этого выполним команду *sudo chmod -R 777 DWVA*(рис. 4)

![Разрешения для папки DWVA](image/ИП2_4.png){#fig:004 width=70%}

## Настройка DVWA

Для настройки и конфигурации DVWA перейдём в каталог DVWA/config: *cd  DVWA/config*. И посмотрим содержимое этого каталога (рис. 5)

![Переход в каталог DVWA/config  и его содержимое](image/ИП2_5.png){#fig:005 width=70%}

## Настройка DVWA

Мы видим файл с именем config.inc.php.dist. Этот файл содержит конфигурации DVWA по умолчанию. Не будем его трогать, и он будет нашей резервной копией, если дела пойдут не так. Вместо этого создадим копию этого файла с именем config.inc.php, которое будем использовать для настройки DVWA: *sudo cp config.inc.php.dist config.inc.php* (рис. 6)

![Создание копии файла config.inc.php.dist](image/ИП2_6.png){#fig:006 width=70%}

## Настройка DVWA

Теперь откроем config.inc.php файл в nano редакторе, чтобы выполнить необходимые настройки. Прокрутим вниз до точки, где мы увидим параметры, такие как db_database, db_user, db_password и т. д. Поменяем эти значения как нам удобно (рис. 7), (рис. 8)

![Открытие файла config.inc.php](image/ИП2_7.png){#fig:007 width=70%}

## Настройка DVWA

![Редактирование файла config.inc.php](image/ИП2_8.png){#fig:008 width=70%}

## Настройка базы данных

По умолчанию Kali Linux поставляется с установленной системой управления реляционной базой данных MariaDB . Поэтому нам не нужно устанавливать никаких пакетов. Сначала запустим службу mysql: *sudo systemctl start mysql* (рис. 9)

![Запуск службы mysql](image/ИП2_9.png){#fig:009 width=70%}

## Настройка базы данных

Проверим запущена ли служба: *systemctl status mysql* (рис. 10)

![Проверка статуса службы mysql](image/ИП2_10.png){#fig:010 width=70%}

## Настройка базы данных

Для входа в базу данных используем команду *sudo mysql -u root -p*. В нашем случае мы используем root, так как это имя суперпользователя, установленное в нашей системе. Появляется командная строка с приглашением “MariaDB”, далее создадим в ней нового пользователя, используя учетные данные из файла config.inc.php с помощью команды *create user 'userDVWA'@'127.0.0.1' identified by "dvwa"* (рис. 11)

![Создание нового пользователя](image/ИП2_11.png){#fig:011 width=50%}

## Настройка базы данных

Теперь нам нужно предоставить этому пользователю полную привилегию над dvwaбазой данных. Выполним команду *grant all privileges on dvwa. to 'userDVWA'@'127.0.0.1' identified by "dvwa"* (рис. 12)

![Предоставление пользователю полных привилегий над dvwa](image/ИП2_12.png){#fig:012 width=70%}

## Настройка сервера Apache

Веб-сервер Apache установлен по умолчанию в Kali Linux. Поэтому нам не нужно устанавливать никаких дополнительных пакетов. Чтобы приступить к настройке Apache2, запустиv nерминал и перейдём в /etc/php/8.2/apache2 (рис. 13)

![Переход в каталог /etc/php/8.2/apache2](image/ИП2_13.png){#fig:013 width=70%}

## Настройка сервера Apache

Далее откроем файл php.ini и найдём строки allow_url_fopen и allow_url_include. Они должны обе иметь значение On (рис. 14), (рис. 15)

![Открытие файла php.ini](image/ИП2_14.png){#fig:014 width=70%}

## Настройка сервера Apache

![Редактирование файла php.ini](image/ИП2_15.png){#fig:015 width=70%}

## Настройка сервера Apache

Далее запустим службу веб-сервера apache с помощью *sudo systemctl start apache2* (рис. 16)

![Запуск службы apache](image/ИП2_16.png){#fig:016 width=70%}

## Настройка сервера Apache

B проверим запущена ли служба: *systemctl status apache* (рис. 17)

![Проверка статуса службы apache](image/ИП2_17.png){#fig:017 width=70%}

## Открытие DVWA в веб-браузере

К этому моменту мы настроили DVWA, базу данных и веб-сервер Apache. Теперь мы можем приступить к запуску приложения DVWA. Запустите веб-браузер и перейдём на страницу http://127.0.0.1/DVWA/setup.php (рис. 18)

![Запуск веб-приложения](image/ИП2_18.png){#fig:018 width=40%}

## Открытие DVWA в веб-браузере

Прокрутив страницу вниз, нажмём кнопку «Создать/сбросить базу данных» в конце страницы (рис. 19)

![Создание базы данных](image/ИП2_19.png){#fig:019 width=70%}

## Открытие DVWA в веб-браузере

Это создаст и настроит базу данных DVWA. Через несколько секунд мы будем перенаправлены на страницу входа в DVWA. Для входа используем учетные данные по умолчанию: 

- Имя пользователя: admin
- Пароль: password (рис. 20)
